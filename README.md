# Greenhouse — Ухаалаг хүлэмж

Greenhouse багийн интерактив dashboard. Одоогийн хувилбар браузер дотор демо өгөгдөл ашигладаг.

## Нээх

`index.html` файлыг браузераар нээнэ. Сервер, Node.js болон интернет шаардахгүй. Хэрэв браузер локал файл дээр өгөгдөл хадгалахыг хязгаарлавал демо хэвийн ажиллах бөгөөд тохиргоо сесс хооронд хадгалагдахгүй.

- **Хяналтын самбар:** температур, агаарын чийг, хөрсний чийг, гэрэл, усны түвшин, төхөөрөмжийн төлөв.
- **Удирдлага:** насос, сэнс, гэрэл тус бүр гар эсвэл автомат горимтой. Демо нөхцөлийг сонгон дүрмээ туршина.
- **Түүх:** мэдрэгч болон хугацааг сонгох, график, сүүлийн хэмжилт, CSV.
- **Анхааруулга:** босго зөрчсөн хэмжилт, төхөөрөмжийн үйлдэл, уншсан төлөв.
- **Тохиргоо:** температур, хөрсний чийг, усны доод түвшин, гэрлийн хуваарь. Цагийн хуваарь браузерын цагийн бүсээр ажиллана.

### Демо турших

1. Удирдлага → насосыг автомат горимд оруул → **Хуурай хөрс** сонго. Ус хангалттай үед насос 10 секунд ажиллана. 60 секундийн завсарлага дуусахад нөхцөл хэвээр бол давтана.
2. Насос ажиллаж байхад **Ус бага** сонго. Насос унтарч, анхааруулга нэмэгдэнэ.
3. Сэнсийг автомат горимд байлга → **Хэт халуун** сонго. Сэнс асна. **Хэвийн нөхцөл** сонгоход температур босгоос 2 °C-ээр бага бол унтарна.
4. Түүхэн өгөгдлөөс мэдрэгч, хугацаа сонгож CSV тат. Тохиргоонд демог анхны төлөвт сэргээж болно.

## ESP32 холболтын сервер

10 секундийн уншилт, 30 хоногийн SQLite түүх, командын баталгаажуулалт бэлэн. Асаах болон firmware-ийн хэрэгжүүлэх гэрээг [ESP32_SETUP.md](ESP32_SETUP.md)-ээс үзнэ үү. Тус файл дахь HTTP гэрээг одоогийн сервер ашиглана.

## Анхны архитектурын төлөвлөгөө

Төхөөрөмж бэлэн болоход ESP32 болон утас/компьютерийг нэг Wi‑Fi сүлжээнд холбоно. Жижиг прототипод ESP32 дээр dashboard болон HTTP API-г хамтад нь байрлуулж болно. Түүхийг олон хоног хадгалах, олон хэрэглэгч ашиглах шаардлагатай бол ESP32 → MQTT → backend → dashboard гэсэн WBS-ийн төлөвлөгөөг ашиглана. Сүлжээний тасалдалтай үед ч насосны хугацаа, усны доод түвшин зэрэг хамгаалалт ESP32 дээр ажиллах ёстой.

Санал болгож буй холболтын гэрээ:

| Үйлдэл | Гэрээ |
| --- | --- |
| Хэмжилт ба төлөв | `GET /api/status` → timestamp, temp (°C), humidity (%), soil (%), light (lux), water (%), relay/mode төлөв |
| Төхөөрөмж удирдах | `POST /api/devices/{pump,fan,lamp}` → горим эсвэл асаах/унтраах хүсэлт, ESP32-ийн баталгаажуулсан төлөв |
| Автомат тохиргоо | `GET /api/settings`, `PUT /api/settings` → баталсан босго, гэрлийн хуваарь |
| Түүх ба анхааруулга | `GET /api/history`, `GET /api/events` → backend эсвэл төхөөрөмжийн хадгалсан өгөгдөл |

Бодит холболтод ESP32 загвар, мэдрэгчийн төрлүүд, GPIO, relay-ийн active-high/low тохиргоо, чийг/усны түвшний калибровк, төхөөрөмжийн цагийн эх үүсвэрийг батална. Командын эрхийг баталгаажуулж, хүсэлт амжилттай илгээгдсэнийг relay төлөв өөрчлөгдсөнтэй ялгана. Демо дүрмүүдийг бодит төхөөрөмжид ашиглахын өмнө шалгаж тохируулна.
